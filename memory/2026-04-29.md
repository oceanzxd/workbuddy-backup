## Hermes浏览器界面修复（v5.3）
- **问题**：聊天输入框消失 + 技能市场按钮无效
- **根因分析**：
  1. CSS Flex布局：`.input-area` 被 `.messages` (flex:1) 挤出可视区，需 `sticky` 定位 + z-index 提升
  2. JS作用域：`switchView`/`loadSkillsView`/`renderSkills` 在IIFE内部，HTML onclick无法访问 → 需暴露到window
- **修复方案**：
  - `#view-chat`: `display:flex!important;flex-direction:column!important;height:100%!important`
  - `.input-area`: `position:sticky;bottom:0;z-index:999` + 红色调试边框(#ff4444)
  - 所有关键JS函数挂到window + try-catch防错
