# 2026-05-08 工作日志

## Hermes QQ Bot 修复（第三次）

### 现象
日志显示 Gateway 在 09:07:23 成功连上（`Ready, session_id=b36207de`），但紧接着 09:07:26 出现第二次启动尝试：
```
Starting Hermes Gateway...
✗ qqbot error: <built-in function kill> returned a result with an exception set
```

### 根本原因
系统中有 **两个 HermesOneClick 进程同时运行**（PID 11196 和 12808）。
第二个实例启动时检测到已有进程，试图 `kill` 清理，但触发了 Windows WinError 87 Bug：
`os.kill(pid, 0)` 对无效 PID 抛异常而非 ProcessLookupError，导致冲突。

### 修复步骤
1. `Stop-Process -Force` 杀掉两个进程
2. `rm -f ~/.local/state/hermes/gateway-locks/*.lock`
3. 重置 `gateway_state.json` → `gateway_state: "stopped"`
4. 重新启动 HermesOneClick

### 预防建议
如果 QQ Bot 再次断线，大概率又是多个进程冲突，每次修复前都先确认进程数。
