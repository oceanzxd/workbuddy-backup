# Memory - 2026-04-30

## Hermes桌面版配置修复

### 问题
桌面版Hermes One-Click报错：
- `Provider 'ocean' is configured but not yet authenticated`
- 原因：`config.yaml`中`skills.external_dirs`格式错误（honcho/timezone错误缩进），且`DEEPSEEK_API_KEY`环境变量未被桌面程序读取

### 修复步骤
1. **修复config.yaml格式**：`honcho: {}`和`timezone: ''`被错误缩进到`skills.external_dirs`内，修正为顶级key
2. **设置Windows用户级环境变量**：`DEEPSEEK_API_KEY`写入User级（PowerShell `[System.Environment]::SetEnvironmentVariable`）
3. **config.yaml直接写密钥**：`providers.ocean.api_key_env`改为`api_key: sk-b54be38aef00444dbe31793afe760815`（不再依赖环境变量）
4. **创建~/.hermes/.env**：写入`DEEPSEEK_API_KEY`和`DEEPSEEK_BASE_URL`

### 结果
桌面版Hermes成功运行，使用`deepseek-v4-flash`模型

### 关键经验
- Hermes桌面程序不会自动读取`.env`文件，必须设置系统级环境变量或直接在`config.yaml`写`api_key`
- `config.yaml`的YAML格式错误会导致整个配置加载失败，Hermes无法启动
- `_config_version: 17`是config.yaml的版本标识，不要修改
