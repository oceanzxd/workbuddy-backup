## Hermes QQ Bot 修复（好运请求）

### 问题诊断
三个根本原因：
1. **微信平台 (weixin) enabled=true 但无 WEIXIN_TOKEN** → 触发 non-retryable startup failed，整个 gateway 崩溃
2. **Stale scoped lock 文件** → `~/.local/state/hermes/gateway-locks/qqbot-appid-5d543ba9cda5f78a.lock` 记录了已死亡 PID 25748，Windows 的 `os.kill(25748, 0)` 抛出 `[WinError 87]` 而不是 `ProcessLookupError`，导致 lock 不被识别为 stale
3. **GATEWAY_ALLOW_ALL_USERS 未设置** → 所有 QQ 用户被拒绝访问

### 修复步骤
1. 编辑 `~/.hermes/config.yaml`：将 `weixin: enabled: false`，给 qqbot 加 `dm_policy: open, group_policy: open`
2. 编辑 `~/.hermes/.env`：添加 `GATEWAY_ALLOW_ALL_USERS=true`
3. 删除 stale lock 文件：`rm ~/.local/state/hermes/gateway-locks/qqbot-appid-*.lock`
4. 重启 HermesOneClick.exe

### 结果
- Gateway state: **running**
- QQ Bot: **connected** (AppID: 1903921146)
- session_id: f3a5ee32-535d-441f-b70e-d4a47315d9d2

### 关键提示（下次复现时）
Windows 上 `[WinError 87] 参数错误` 在 Hermes 网关启动时 = stale lock 文件问题，删 `~/.local/state/hermes/gateway-locks/` 目录下的 lock 文件即可。

## agent_brain 个人知识库大脑（v2.0）

### 完成时间
2026-05-01

### 做了什么
构建了 `agent_brain` 系统，把 90 个技能和 9 条记忆全部索引到 SQLite 数据库：
- 数据库位置：`~/.workbuddy/agent_brain/brain.db`（284KB）
- 脚本位置：`~/.workbuddy/agent_brain/agent_brain.py`
- 技能索引：90 个（含分类、触发词、使用次数）
- 记忆索引：9 条（来自 `~/.workbuddy/memory/` 和工作区 memory）

### 核心功能
| 命令 | 作用 |
|:-----|:-----|
| `python agent_brain.py init` | 初始化数据库 |
| `python agent_brain.py index` | 全量重建索引（技能+记忆）|
| `python agent_brain.py scan <任务>` | 扫描相关技能（LIKE+FTS5 双引擎）|
| `python agent_brain.py recall <词>` | 搜索历史记忆 |
| `python agent_brain.py status` | 查看状态面板 |
| `python agent_brain.py stats` | 技能使用统计 |
| `python agent_brain.py record <任务> [技能]` | 记录任务执行 |
| `python agent_brain.py rebuild` | 完全重建数据库 |

### 关键设计
- **中文搜索**：LIKE 优先（逐词拆 gram），FTS5 作为英文补充
- **技能分类**：自动分类为 通用工具/金融交易/市场分析/浏览器自动化 等
- **自建标记**：`agent_created=1` 的技能打 ✓ 标记（如 `hermes-qqbot-fix`、`agent-brain-manager`）

### 已知问题
- 搜索排名按 `use_count DESC`，新技能（0次）排后面 → 后续可加关键词匹配度权重
- FTS5 对中文分词支持差 → 已用 LIKE gram 搜索解决
- `scan` 拆分中文为 2-3字 gram，可能产生噪音关键词

### 下次使用
```bash
# 接到任务后，先扫描
python ~/.workbuddy/agent_brain/agent_brain.py scan "用户任务描述"
# 根据返回的技能列表，用 Skill 工具加载最相关的技能
```
