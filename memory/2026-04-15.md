**学习要点总结**:

#### 1. Harness 工程核心思想
```
Agent Loop: messages[] → LLM → response → (tool_use? execute : return) → loop
Harness: 可变机制（工具/技能/任务/隔离），不变是Agent Loop
```

#### 2. Hermes Agent 核心优势
- **自我进化能力** - 内置闭环学习系统，自动创建和优化技能
- **三层记忆系统** - MEMORY.md + USER.md + 技能库
- **模型无关架构** - 支持 200+ 模型
- **16+ 消息平台** - Telegram、Discord、微信等
- **6 种执行后端** - 本地、Docker、SSH、Daytona、Singularity、Modal

#### 3. 实际应用实践
- **股票早盘分析 Skill** - 效率提升 90%
- **交易记忆系统** - MEMORY.md 配置
- **定时自动化任务** - Cron 系统
- **子代理协作分析** - 多代理并行处理

#### 4. 技能开发要点
```yaml
Skill = SKILL.md + references/ + assets/

SKILL.md 结构：
- YAML Frontmatter（元数据）
- 使用说明

```

#### 5. 子代理协作模式
```
主代理 (Coordinator)
```
